## Игра
- Phaser 3 + Vite. Код: `/Users/maksimilin/Desktop/Dark Fantasy/dark-fantasy-rpg/` (src/scenes/MapScene.js, BattleScene.js, src/data/maps.json, battles.json, public/maps/gen/maps_build.json, src/systems/WalkableZones.js, src/dev/MapEditor.js). Можешь читать, чтобы понять причину бага.
- Тестовая копия (свежая сборка, то же, что на проде): **http://127.0.0.1:5190/dark-fantasy-rpg/**. Прод не трогай.
- Базовый холст 1280×720, масштаб FIT. Клики по холсту: `page.mouse.click(x, y)` в координатах окна (при окне 1280×720 они совпадают с координатами игры).
- В этой сборке есть `window.__game` (Phaser.Game): для чтения состояния и для телепорта, если до места долго идти:
  `__game.scene.getScenes(true)[0].scene.start('LoadingScene',{destination:'MapScene',destinationData:{mapKey:'<id>',spawnId:'default'}})`. Список карт: ключи `src/data/maps.json`. Бой: `destination:'BattleScene', destinationData:{battleId:'<id из battles.json>', fromMapKey:'...', fromSpawnId:'default'}`.
  Но главное: **играй мышью, как игрок**. Телепорт только чтобы сэкономить время.
- Новая игра: `localStorage.clear()`, перезагрузка, затем на титуле кнопка «Новая игра» (~640, 590); под ней переключатель режима Хроника / Железо (~530, 650 и ~750, 650).

Свои скрипты клади в свою папку отчёта и запускай `node <скрипт>` с `cwd` в папке pp (или `NODE_PATH`), чтобы находился puppeteer-core.
Запуск Chrome:
```js
puppeteer.launch({ executablePath: '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome', headless: 'new',
  userDataDir: '/tmp/pp-udd-qa-<твоя-роль>', args: ['--use-angle=swiftshader','--enable-unsafe-swiftshader','--autoplay-policy=no-user-gesture-required'],
  defaultViewport: { width: 1280, height: 720 } })
```
Удобный приём: один долгий скрипт-сценарий, который делает серию действий и после каждого шага снимает скриншот (`page.screenshot`), собирает `pageerror` и ошибки консоли. Скриншоты смотри сам (инструмент Read умеет картинки). Для анимаций снимай серии кадров с шагом 30-50 мс.
Не запускай больше одного Chrome одновременно. Серверы не запускай и не останавливай.
