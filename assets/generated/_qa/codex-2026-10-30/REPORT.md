# Мортис: понятность начала, боя и знаний, 30.10.2026

Ветка revision-2026-10. Баланс, готовый арт и production не изменены.

## Изменения

- Мирное решение встречи у телеги теперь открывает разговор с Агной о похоронах. Раньше условие требовало записку, которая выдаётся только после боя. Старый боевой путь также сохранён; принятый исход скрывает повторную награду.
- В текущих этапах четырёх ранних заданий появились подсказки: разговор с мародёрами, Агна и отдых, разрешение Ворна читать книгу, Мира и пёс. Будущие этапы не раскрываются.
- Правая колонка журнала обрезается по рамке и прокручивается отдельно от списка. Выбор нового задания сбрасывает прокрутку. При перерисовке удаляются ссылки на старые объекты.
- Наведение на бойца показывает HP, броню, ряд, эффекты, причину недоступности цели, штраф обхода и фактическое лечение до максимума HP. Формулы боя не менялись, расчёт подсказки не тратит ресурсы и не вызывает RNG.
- Книги получили дополнительные страницы заметок из effects: рецепт, навык, предметы, опыт и авторское effectText. Исходный текст сохранён; повторное чтение не выдаёт награды снова.
- Подсказки расходников показывают заданную в данных цель следующего боевого эффекта и ограничение фляги между привалами. Неопределённая цель пива вынесена в Д40.

## Проверки

- `npm test`: 39/39. Новые проверки: мирный доступ к похоронам и запрет повторной награды, цель лечения, закрытый задний ряд/пистолет, ограничение лечения максимумом HP, отсутствие побочных эффектов предпросмотра, сведения книг/расходников.
- `npm run build`, `npm run check:build`: 548 МиБ, 684 ссылки на листы анимаций и NPC проверены, один входной JS-пакет. Остаётся стандартное предупреждение Vite о размере JS-пакета.
- `tools/qa/readability-route.cjs`: новый профиль Chrome, штатные диалоги и награды, без выдачи XP через registry. Переходы по маршрутам выходов. Встреча Корвина запускается приближением героя. 25 + 10 + 15 + 15 + 68 = 133 XP, второй уровень героя и резервного Ворнага. Покупка хлеба, привал, перезагрузка; F5 во время прокачки восстанавливает выбор, повторная F5 после завершения не повторяет его. Ошибок страницы и загрузки нет.
- `tools/qa/readability-ui.cjs`: отдельные подготовленные состояния боя и книги; закрытый ряд, лечение 67 → 70, заметки травника. Для проверки прокрутки текст задания временно утроен только в памяти тестового браузера. Ошибок страницы и загрузки нет.
- Скриншоты просмотрены: `target-blocked.png`, `target-heal.png`, `book-knowledge.png`, `journal-hints.png`, `journal-long-scroll.png` в этой папке. PNG и JSON результатов игнорируются Git.

Запуск QA: локальный Vite на 127.0.0.1:5178, Chrome в /Applications, переменная MORTIS_PUPPETEER указывает на puppeteer-core (использована изолированная установка /tmp/mortis-browser-qa/node_modules/puppeteer-core).

## Границы проверки

Один мирный путь доказывает достижимость второго уровня, но не заменяет тест темпа чтения за первые 30–45 минут и прохождение всех развилок. Боевые подсказки показывают броню и модификаторы, не обещают точный случайный урон. Книжные заметки описывают уже существующие эффекты, не добавляют новых наград. Привал в маршрутном тесте вызван штатным методом сцены; стоимость номера через диалог в этом тесте не проверялась.
