Файлы `*_overlay.png` сняты с наложением, которое я рисовал поверх сцены. **Зелёное**: то, что игра считает проходимым (`m.walkable.zones`). **Красное**: зоны выходов из maps.json. Координаты в отчёте экранные (окно 1280x720); мировые = экранные / 0.765.

Общая причина большинства проблем с ходьбой: `MapUnit.moveTo` (src/entities/MapUnit.js:156-200) ведёт героя по прямой. В MapScene.js:179 к проходимой зоне подгоняется только КОНЕЧНАЯ точка клика (`walkable.clamp`). Обхода препятствий нет, поэтому даже при правильной разметке герой по пути идёт сквозь лес, стены, воду и крыши.
