# Этап 3: выходы маршрута начала игры

`<карта>__<куда>_hover.jpg`: курсор над выходом (подсветка, табличка с названием места, курсор «перейти» или «дверь»).

Сценарий (скрипт exits.mjs в рабочей папке сессии): для каждого выхода 9 карт маршрута навести курсор на зону и один раз кликнуть.
Итог: 26 выходов, все открытые переводят на свою карту с первого клика (герой идёт по пути), два закрытых
(Северный тракт, люк в погреб) показывают причину и не пускают. Ни одна табличка не вылезает за кадр и не ложится под HUD.
Тест `test/walkgrid.test.mjs`: зоны выходов маршрута не меньше 64×64 экранных px и не пересекаются с HUD (`src/data/ui.json`, hud).
