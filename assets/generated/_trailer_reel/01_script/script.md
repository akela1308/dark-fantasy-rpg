# Рилс «Расчёт». 9:16, 29 с

Одна фраза: триста лет старая семья выплачивала троллю долг за мост, а когда последняя монета легла, оказалось, что он всё это время держал мост на плече.

Придумано для рилса: семья, плечо под мостом, старуха. Из лора: тролль ждёт расчёта, монстры с работой, долг переживает должника.
