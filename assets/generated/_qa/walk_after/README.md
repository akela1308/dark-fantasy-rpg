# Этап 2: где можно ходить (маршрут начала игры)

`<карта>_before.jpg`: автоматические зоны до правки (из `_qa/maps/shots`).
`<карта>_after.jpg`: ручная сетка 24 px поверх кадра из игры. Зелёное можно, красное нельзя, оранжевые рамки выходы, голубые точки спавны.
`demo_*.jpg`: путь героя в игре (жёлтая линия) и знак «нельзя» при клике по крыше.

Карты: south_post, three_pillars, three_pillars_inside, map1, tavern_map, tavern_inside, old_mill, mill_inside, burned_hamlet.

Проверка: на каждой карте 25 случайных кликов, кадр за кадром ни герой, ни спутники не встают на закрытую клетку
(одно касание угла спутником на 1 px в tavern_inside). Тест `test/walkgrid.test.mjs`: на всех 59 картах спавны стоят
на проходимых клетках и все выходы достижимы.

Пересобрать картинку: `python3 tools/walkgrid.py render <карта> out.jpg --shot=<кадр из игры>.png`.
