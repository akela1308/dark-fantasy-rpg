## Шаг 1. Завершение боевых действий

- До исправления добивающий удар запускал итог боя на кадре 18 из 23. После: все 23 кадра, затем победа. Эффект удара остался на прежнем hitFrame.
- Перевязка использует существующий cast2: HP 20 -> 38 после кадра применения, Сборы 3 -> 2. Начало клипа не лечит мгновенно.
- Стойка Дуэлянта использует существующий block. Припарка, отвар живицы и соль используют существующий cast2; финишер Дуэлянта использует shot.
- На время действия ввод блокируется, кнопки убираются, подпись показывает действующего бойца. Запасная анимация без загруженного листа тоже блокирует повторный ввод.
- Завершение действия переживает прерывание смертью (например, ответный выпад). Возврат в стойку не прерывает победную анимацию.
- Враг с первой инициативой начинает ход при входе в бой. Раньше create не запускал ИИ; засада зависала.

Проверка: tools/qa/battle-flow.cjs, настоящий headless Chrome, изолированное хранилище. Семь сценариев: добивание/повторный ввод, лечение, навык на себя, запасная анимация, смерть атакующего/поражение Железа, первый ход врага/засада, F5 в бою Железа. Ошибок JS и HTTP нет. Управляемые фикстуры меняют HP/инициативу только внутри тестового браузера; это не проверка баланса.
