## Шаг 2. Сохранения и стартовый маршрут

- ProgressionRecovery восстанавливает незавершённые повышения: опыт отряда уже записан, но уровни юнитов ниже. После F5 снова открываются реальные выборы для героя и запаса, без повторной награды. Завершённые уровни не повторяются.
- На время выбора карта не двигает отряд, не запускает встречи и не принимает ввод. После выбора состав на карте обновляется.
- Результат боя сохраняется немедленно, до задержки показа итогового окна. Раньше в Железе оставалось окно 800 мс, когда уже выигранный бой ещё считался брошенным при F5.
- Добавлены три регрессии сохранений: незавершённый уровень, откат Хроники к привалу, F5 Железа до/после победы.

Браузерный маршрут tools/qa/start-route.cjs: новая Хроника -> мирный исход с мародёрами (25 XP) -> Ворнаг в запас -> old_mill -> burned_hamlet -> three_pillars -> map1 -> tavern_map -> tavern_inside. Переходы выполнялись через поиск пути и движение героя, без телепортации. Диалоги выбирались клавишами; NPC открывались через их обработчики клика. Куплен хлеб кликом по строке лавки: золото 12 -> 9, хлеб +1. Отдых и F5 сохранили карту и найм. Контрольная добавка XP до 100 использовалась только для проверки восстановления второго уровня, это не измерение естественного темпа прокачки.

Снимки route-*.png, shop-vorn.png, level2-before-reload.png, level2-recovered.png; route-results.json. Окна лавки и уровня просмотрены. Ошибок JS/HTTP нет. npm test: 32/32, production build успешна.

## Шаг 3. Понятность боя и надёжность сборки

- Под очередью ходов видны фактические ресурсы действующего бойца и его состояния. Подсказки портретов в очереди показывают HP, ресурсы и состояния, подсказки навыков показывают стоимость и пополнение ресурса.
- Кольца целей учитывают закрытый задний ряд. В контрольном построении обычный удар подсвечивает 2 передние цели, пистолет все 4. Очередь следующего раунда учитывает корни и не переносит бонус засады на следующий раунд.
- Описание Железа уточнено по фактическому правилу: гибель героя и перезагрузка в бою стирают сохранение.
- Найдена и исправлена ошибка срока Дуэльной стойки: duration=1 снимался endTurn сразу после применения, ещё до вражеского действия. Теперь 30% уклонения переживают ответ врага и заканчиваются после следующего хода героя; значения навыка в JSON не менялись. Новые тесты проверяют этот цикл и соответствие показанных ресурсов реальной цене пистолета.
- Запасной эффект нелечащей поддержки показывает золотой импульс, без ложной надписи +HP.
- emptyOutDir включён: повторная сборка очищает старые пакеты и ассеты. Вместо накопившихся 671 МиБ чистая production-сборка занимает 548 МиБ. Повторная сборка не накапливает entry-bundle. npm run check:build проверяет лимит 1 ГиБ, наличие 684 файлов анимаций/NPC, отсутствие вариантов карт и старых entry-bundle. Проверку запускать после npm run build.

Production smoke: вход с титула, клик по мародёру, выбор боя через клавиатуру, загрузка боевых анимаций. Ошибок JS/HTTP нет; отладочный window.__game отсутствует. На localhost до первого боя загружено около 28 МиБ, 314 запросов; это не замер скорости интернета. Снимки production-map.png, production-battle.png, production-skill-tooltip.png, production-battle-1920-dpr2.png; production-results.json.

Браузерный battle-flow дополнен проверкой ресурсов/целей и полным боем с мародёрами отдельно в Хронике и Железе: обычные статы, ресурсы и ИИ, без подмены HP/урона.
