# Плейтест Mortis (Dark Fantasy RPG): общая вводная для тестировщиков

Ты тестировщик игры. Задача: играть как живой человек, искать всё, что выглядит криво, нелогично, непропорционально, неудобно или сломано, и записывать это с доказательствами. **Код игры не правишь**, только наблюдаешь и записываешь.

## Игра
- Phaser 3 + Vite. Код: `/Users/maksimilin/Desktop/Dark Fantasy/dark-fantasy-rpg/` (src/scenes/MapScene.js, BattleScene.js, src/data/maps.json, battles.json, public/maps/gen/maps_build.json, src/systems/WalkableZones.js, src/dev/MapEditor.js). Можешь читать, чтобы понять причину бага.
- Тестовая копия (свежая сборка, то же, что на проде): **http://127.0.0.1:5181/dark-fantasy-rpg/**. Прод не трогай.
- Базовый холст 1280×720, масштаб FIT. Клики по холсту: `page.mouse.click(x, y)` в координатах окна (при окне 1280×720 они совпадают с координатами игры).
- В этой сборке есть `window.__game` (Phaser.Game): для чтения состояния и для телепорта, если до места долго идти:
  `__game.scene.getScenes(true)[0].scene.start('LoadingScene',{destination:'MapScene',destinationData:{mapKey:'<id>',spawnId:'default'}})`. Список карт: ключи `src/data/maps.json`. Бой: `destination:'BattleScene', destinationData:{battleId:'<id из battles.json>', fromMapKey:'...', fromSpawnId:'default'}`.
  Но главное: **играй мышью, как игрок**. Телепорт только чтобы сэкономить время.
- Новая игра: `localStorage.clear()`, затем клик по «[ НАЧАТЬ ИГРУ ]» на титуле (~640, 600).

## Инструмент
Браузер: свой headless Chrome через puppeteer-core (расширение Chrome не используй, оно общее на всех).
Готовый пакет: `/private/tmp/claude-501/-Users-maksimilin-Desktop-Dark-Fantasy-dark-fantasy-rpg/2e440813-a4bf-49db-91eb-aa21118b1c8d/scratchpad/pp/` (там node_modules с puppeteer-core, примеры run.mjs и tour.mjs). Свои скрипты клади в свою папку отчёта и запускай `node <скрипт>` с `cwd` в папке pp (или `NODE_PATH`), чтобы находился puppeteer-core.
Запуск Chrome:
```js
puppeteer.launch({ executablePath: '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome', headless: 'new',
  userDataDir: '/tmp/pp-udd-qa-<твоя-роль>', args: ['--use-angle=swiftshader','--enable-unsafe-swiftshader','--autoplay-policy=no-user-gesture-required'],
  defaultViewport: { width: 1280, height: 720 } })
```
Удобный приём: один долгий скрипт-сценарий, который делает серию действий и после каждого шага снимает скриншот (`page.screenshot`), собирает `pageerror` и ошибки консоли. Скриншоты смотри сам (инструмент Read умеет картинки). Для анимаций снимай серии кадров с шагом 30-50 мс.
Не запускай больше одного Chrome одновременно. Серверы не запускай и не останавливай.

## Что уже известно от владельца (подтверди, измерь, уточни причину; не ограничивайся этим)
1. **Масштаб:** персонажи на картах слишком маленькие относительно телеги, столба, деревьев, зданий. Собака в бою гигантская (раньше была нормальной). Нужны реальные пропорции: человек ~1,75 м, дверь ~2 м, телега, собака по колено-бедро и т.д.
2. **Где можно ходить:** герой ходит по лесу, по крыше мельницы, сквозь здания. Раньше на старых картах владелец сам размечал клетки ходьбы. На новых картах границ фактически нет.
3. **Перекрытие:** мебель/объекты на переднем плане должны закрывать героя, за спиной героя — наоборот (как столы с гномами в таверне). Никто не ходит поверх мебели и крыш.
4. **Бой:** у мародёра и собаки иногда на один кадр силуэт разворачивается вправо, потом обратно (мигание флипа).
5. **UI:** журнал, лог боя, панель навыков, окна — квадратные некрасивые рамки; подписи навыков налезают друг на друга («Укол в уязвимостьДуэльная стойка»). Красивая только нижняя панель с иконками и окно персонажа.
6. **Чёрная полоса справа** на первой карте (раньше карты занимали весь экран).
7. **Выходы:** непонятно, куда идти и как выйти с карты: нет подсветки зоны, стрелки, надписи «куда ведёт» при наведении. Из мельницы не выйти: нарисованная дверь ничего не делает, тёмный проход внизу слева тоже без подсказки.
8. На первой карте в левую треть не пройти, и непонятно почему.

## Отчёт
Пиши в `/Users/maksimilin/Desktop/Dark Fantasy/dark-fantasy-rpg/assets/generated/_qa/<твоя-роль>/REPORT.md`, скриншоты в ту же папку (jpg/png с понятными именами). Формат каждой находки:
```
### <N>. <коротко>   [критично | важно | косметика]   [карта/экран]
Что: ...   Ожидал: ...   Как повторить: ...   Доказательство: <файл скриншота>
Причина в коде (если нашёл): file:line
```
В начале отчёта: что ты успел пройти (карты, бои, окна), сколько времени, сколько находок по степеням. Пиши по-русски, без длинного тире (символ U+2014 запрещён). Не правь код, не коммить, ничего не удаляй вне своей папки отчёта.
Бюджет: до ~90 минут работы. Лучше 25 точных находок с доказательствами, чем 80 расплывчатых.
